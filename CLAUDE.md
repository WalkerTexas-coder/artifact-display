## Business Model & Operations

### **Target Market**
- **Patients with Complex Conditions:** Multiple, interconnected symptoms requiring sophisticated pattern recognition

- **vs. Traditional Telehealth:** Depth of analysis with sophisticated AI vs basic symptom matching
- **vs. Longevity Platforms:** Medical detective work for existing complex conditions vs optimization for healthy individuals
- **vs. Specialty Platforms:** Integration with complete care ecosystem vs fragmented point solutions

## Data Management & Compliance

### **Data Retention Requirements**
- **Medical Records:** 7-year minimum retention for all patient medical records including AI assessments
- **HIPAA Compliance:** All stored data encrypted and maintained according to requirements
- **Tiered Storage:** Active < 30 days, Cold < 120 days, Glacier < 18 months
- **Audit Logging:** Comprehensive audit logs of all data access for compliance reporting
- **Legal Holds:** Provisions for legal holds overriding standard retention policies

### **Order Hierarchy System**
**Three-Level Structure:**
- **Master Order:** #HF-XXXX format
- **Sub-Categories:** -S-X (subscriptions), -C-X (consultations), -L-X (lab kits), -A-X (appointments)
- **Sub-Sub Categories:** -F-X (fills for medication deliveries), recurring instances

**Examples:**
- Membership: #HF-2009-S-1
- First medication fill: #HF-2009-S-1-F-1
- Follow-up appointment: #HF-2010-A-1
- Lab kit: #HF-2009-L-1

## Project Overview

This is a Next.js 15 application designed as a **Feature Prototype Showcase Platform** for Hedfirst development team communication. The application serves as a visual specification tool where Austin Walker (Product Manager) can craft interactive prototypes to demonstrate expected user interactions and feature requirements before creating development tickets.

**Primary Purpose:**
- Create interactive prototypes showcasing expected user interactions
- Provide clear visual specifications for development tickets
- Demonstrate complex UI/UX patterns for the Hedfirst platform
- Serve as a reference for developers implementing features on the Teligant platform

The project uses TypeScript, Tailwind CSS v4, and React 19 with Next.js 15 App Router.

## Development Commands

- `npm run dev` - Start development server with Turbopack (opens on http://localhost:3000)
- `npm run build` - Build production application
- `npm start` - Start production server
- `npm run lint` - Run ESLint

## Architecture

### File Structure
- `app/` - Next.js App Router directory containing pages and layouts
  - `layout.tsx` - Root layout with font configuration and global styles
  - `page.tsx` - Home page component
  - `globals.css` - Global CSS with Tailwind imports and custom properties
- `public/` - Static assets (SVG icons)
- `next.config.ts` - Next.js configuration (currently minimal)

### Key Technologies
- **Next.js 15** with App Router and Turbopack for fast development
- **TypeScript** with strict mode enabled
- **Tailwind CSS v4** with PostCSS configuration
- **Geist** font family (sans and mono variants) loaded via `next/font`

### Styling System
- Uses Tailwind CSS v4 with custom CSS properties for theming
- Dark mode support via `prefers-color-scheme` media query
- Custom color variables defined in `globals.css` for background/foreground
- Font variables configured in layout and referenced in CSS

### TypeScript Configuration
- Strict mode enabled with modern ES2017 target
- Path alias `@/*` configured for root-level imports
- Next.js plugin enabled for enhanced TypeScript support
